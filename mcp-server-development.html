// faq

Questions, answered.

MCP (Model Context Protocol) is a standard way for AI agents like Claude to securely use external tools and data. An MCP server exposes your systems — databases, APIs, files — to the AI in a controlled way.

Databases, CRMs, internal APIs, file systems, payment platforms, Google Workspace — any system with an interface can be exposed as MCP tools or resources.

Yes, when done properly: scoped permissions, read-only modes, authentication, input validation and audit logging are built into every server we ship.

Every MCP server ships with setup guides, tool documentation and tests — plus optional ongoing maintenance as the protocol evolves.
